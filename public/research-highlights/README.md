# Research-highlight slider media

Add one landscape JPG or PNG for each slider result. Recommended: 1600 × 1000 px or larger.

Use these exact file names:

- `machine-deep-learning.jpg` — machine learning / deep learning result
- `image-to-image.jpg` — image-to-image transformation result
- `enhancement-restoration.jpg` — image enhancement or restoration result
- `detection-tracking.jpg` — object detection or tracking result
- `crowd-counting.jpg` — crowd counting / density-map result

The slider changes automatically every 4 seconds, but visitors can use the arrows and dots to control it. It shows a clean abstract placeholder until each image is added.

## Optional video

The tracking slide is already configured to use a muted, looping video when this file is present:

- `detection-tracking.mp4`

Without that file, it automatically falls back to `detection-tracking.jpg`. Other slides can be configured the same way later without changing the layout.

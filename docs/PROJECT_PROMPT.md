# Canonical Design Prompt

Create a calm bilingual academic website for Vision and Learning Lab using Next.js. Preserve the metallic-orange VL identity, a research-first information architecture and the “From Pixels to Intelligence” message. Use softly rounded typography, generous whitespace, dark charcoal, warm copper-orange and off-white surfaces.

The hero must prioritize typography and research content. Keep at most one restrained visual effect—the slow VL mark in the hero. Avoid decorative motion, carousels, videos, dense particle fields, aggressive camera movement and gaming aesthetics.

The site supports English and Vietnamese through explicit `/en` and `/vi` routes, opens English by default, and has a visible language switcher. English uses a rounded display identity; Vietnamese prioritizes clean diacritic rendering while retaining rounded headings.

Use a simple information hierarchy: Home, About the Lab, People, Publications, News and Contact. About the Lab contains the introduction, verified statistics, research focus and research areas. Preserve mobile, reduced-motion, light/dark theme and static-export compatibility with GitHub Pages deployment.

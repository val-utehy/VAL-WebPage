# Canonical Design Prompt

Create a premium bilingual academic website for Vision and Learning Lab using Next.js and lightweight vanilla Three.js. Preserve the metallic-orange VL identity, the research-first information architecture and the “From Pixels to Intelligence” message. Use softly rounded typography, generous whitespace, dark charcoal, warm copper-orange and off-white surfaces.

The hero must prioritize typography and research content. Use an elegant, living neural-flow background: a shader-deformed wire surface, a layered depth-particle field, several muted signal paths with small moving pulses, and soft expanding focus rings that respond gently to the pointer. Do not render a 3D VL logo in the hero. Keep the palette nearly monochrome with warm copper highlights; avoid rainbow gradients, heavy bloom, aggressive camera movement and gaming aesthetics.

The site supports English and Vietnamese through explicit `/en` and `/vi` routes, browser-language detection and a visible language switcher. English uses a rounded display identity; Vietnamese prioritizes clean diacritic rendering while retaining rounded headings.

Include one cinematic research-film section after the introduction. Surround the HTML video with a very subtle Three.js point field and a single slow orbit. Preserve mobile, reduced-motion, light/dark theme and non-WebGL fallbacks. The site must remain suitable for static export and GitHub Pages deployment.
